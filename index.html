Core Rules

점수 높은 종목을 추격하지 않고, 좋은 눌림만 기다립니다.

01

80점 이상은 매수 버튼이 아님

강한 후보/알림/보유 관리 구간이며, 신규 진입은 눌림과 15M 트리거를 확인합니다.

02

최적 진입은 70~79점

Broad는 넓게, Main은 압축하고, 70~79점에서 좋은 눌림이 나오면 진입 우선순위가 높습니다.

03

Red에서만 완전 중단

Green은 적극, Yellow는 선별, Orange는 초저위험, Red는 신규 진입 금지로 운용합니다.

Market Regime Filter

좋은 장만 매매하지 않고, 장 상태별로 강도를 바꿉니다.

Green

Normal

BTC 1H/4H 구조 양호, USDT.D 안정, 알트 순환매 가능.

  • Broad / Main / A++ 정상 작동
  • 70~74점 소액 1차 가능
  • TP2/TP3/러너 적극
Main -1.0% · A++ -3.0%

Yellow

Selective

BTC 횡보/약한 하락, 시장은 애매하지만 개별 종목 OI가 살아있음.

  • Broad는 관찰만
  • 75점 이상 + 좋은 눌림
  • TP1 빠르게, BE 우선
Main -0.75~1.0% · A++ -2.0%

Orange

Ultra low risk

시장 약세지만 특정 종목의 숏 과열/음펀비/강한 지지가 존재.

  • 일반 롱 금지
  • A++ 롱만 초저위험
  • 숏 후보도 초저위험
A++/Short -0.5~1.0%

Red

No entry

BTC 급락 + OI 급증, 디레버리징, 호가 붕괴, 극단 변동.

  • 신규 진입 금지
  • 자동매매 OFF
  • 기존 포지션 관리만
Risk: 신규 진입 없음

Four-stage Filter

넓게 포착하고, 엄격하게 압축합니다.

Broad Radar Filter

매수 신호가 아니라 관심 종목 등록 신호입니다. 차트와 눌림을 관찰합니다.

  • OI Chg 4H ≥ 2%
  • OI Chg 24H ≥ 5%
  • OI / MktCap ≥ 0.15%
  • Long 1H ≤ 52%
  • L/S Ratio 1D ≤ 1.05

Main Long Squeeze Filter

실제 롱 매매 후보를 압축하는 핵심 필터입니다.

  • OI Chg 4H ≥ 3%
  • OI Chg 24H ≥ 8~10%
  • Long 1H ≤ 49%
  • L/S Ratio 1D ≤ 0.9
  • FR AVG ≤ 0

A++ Long Squeeze Filter

강한 후보/우선순위/러너 후보입니다. 추격매수 신호가 아니라 눌림 대기 신호입니다.

  • OI Chg 4H ≥ 5%
  • OI Chg 24H ≥ 15%
  • OI / MktCap ≥ 0.3%
  • Long 1H ≤ 46~48%
  • Net Long 증가 + FR AVG < 0

Short / Long Ban Filter

숏 후보를 찾거나, 롱 우선 운용에서 위험한 신규 롱을 차단합니다.

  • OI Chg 4H ≥ 3%
  • Long 1H ≥ 55~60%
  • L/S Ratio 1D ≥ 1.2
  • FR AVG > 0
  • 상단 BSL / OB / FVG 저항 중첩

Score Bands

점수 구간은 진입 버튼이 아니라 행동 지침입니다.

0~59Ignore
60~69Radar
70~74Early Main
75~79Main Entry
80~87Strong / No chase
88+Overheat

Pullback Engine v1

1H가 자리를 만들고, 15M이 타이밍을 줍니다.

자동매매 v1은 1H OTE, VWAP 지지, 돌파구간 리테스트를 핵심 기준으로 사용합니다.

1H

Pullback Score

  • 1H OTE 0.618~0.786
  • VWAP line 또는 Band#1 지지
  • 이전 1H 저항 돌파 후 지지 전환
  • 핵심 기준 2개 이상: 일반 진입 가능
  • 핵심 기준 3개: A급 눌림
15M

Trigger

  • 눌림 터치 후 15M 종가 회복
  • 긴 아랫꼬리 또는 직전 고점 돌파
  • 거래량 증가, OI 유지/재증가
  • VWAP 또는 MSB flip level 재회복
  • 기본 1개 이상, A급 2개 이상
Entry

3분할 진입

1차 30% 2차 40% 3차 30%

1차 후 구조가 깨지면 2차/3차 추가진입은 금지합니다.

Risk · SL · TP

TP1에서 리스크를 제거하고, TP2/TP3/러너로 수익을 확장합니다.

Risk Guard

  • Daily -4%: 신규 진입 중단
  • Daily -6%: 전체 매매 중단
  • Weekly -8%: 리스크 절반 축소
  • Weekly -12%: 해당 주 신규 진입 중단
  • 단일 거래 손실은 항상 Seed -5% 이하

Structure SL

  • 롱: 눌림구간 최저점 이탈
  • 롱: VWAP / OTE / Retest 지지 실패
  • 숏: 저항구간 상단 돌파 및 안착
  • 구조가 애매하면 0.5~1 ATR 보정
  • 손절 후 같은 자리 즉시 재진입 금지

TP Ladder

  • TP1: +1R 또는 최근 1H 스윙, 30% 익절
  • TP1 후 SL을 BE 또는 손실 최소 구간 이동
  • TP2: +2R 또는 1H Weak High, 40% 익절
  • TP3: +3R 이상 또는 4H Weak High
  • 러너는 데이터 구조가 살아 있을 때만 유지

Automation Flow

스캔부터 알림까지 12단계로 실행합니다.

  1. 전 종목 스캔
  2. Market Regime 판정
  3. Broad / Main / A++ / Short-Ban 분류
  4. 유동성 / 스프레드 필터 확인
  5. 스퀴즈 점수 계산
  6. 점수 구간 판정
  7. 1H Pullback Engine 계산
  8. 15M Trigger 확인
  9. 진입 등급 결정
  10. 3분할 진입 계획 생성
  11. SL / TP1 / TP2 / TP3 계산
  12. 텔레그램 알림 발송
