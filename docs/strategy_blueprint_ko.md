# 알트코인 선물 스퀴즈 전략 블루프린트 v1

## 1. 목표

Coinalyze, Coinglass, 거래소 선물 데이터를 활용해 월 20~40회 수준의 고선별 알트코인 선물 매매 후보를 생성한다. 전략은 롱/숏 양방향을 유지하되, 현재 기본 실행 모드는 롱 우선이다.

이 시스템은 “좋은 장에서만 매매하는 시스템”이 아니라, 시장을 Green / Yellow / Orange / Red 4단계로 나누고 각 상태에 따라 진입 기준, 필터 강도, 리스크, TP 방식을 조절한다.

## 2. 기본 운용 원칙

1. 알트코인은 기본 5배 레버리지 기준으로 본다.
2. 롱/숏 양방향 전략을 유지하되 기본 실행 모드는 롱 우선이다.
3. 숏 조건은 숏 진입용뿐 아니라 Long Ban, 리스크 회피, 헷징 참고용으로 활용한다.
4. 80점 이상은 강한 후보 또는 알림 구간이며, 실제 진입은 눌림구간과 15M 트리거를 확인한다.
5. 가장 좋은 진입은 70~79점 구간에서 좋은 눌림이 나올 때다.
6. 거래 등급과 시장모드에 따라 리스크를 다르게 설정한다.
7. 어떤 경우에도 1회 손실은 시드 -5%를 넘지 않도록 한다.

## 3. Market Regime Filter

No Trade Filter는 단순 매매 금지 장치가 아니라 Market Regime Filter로 사용한다.

## 4. 필터 구조

### 4.1 Broad Radar Filter

목적은 초기 후보를 넓게 잡기 위한 레이더이며, 매수 신호가 아니라 관심 종목 등록 신호다.

조건:

- OI Chg 4H ≥ 2%
- OI Chg 24H ≥ 5%
- OI / MktCap ≥ 0.15%
- Long 1H ≤ 52%
- L/S Ratio 1D ≤ 1.05
- FR AVG는 약한 양펀비까지 허용 가능

시장모드별 사용:

- Green: 관찰 + 조건 충족 시 진입 후보 가능
- Yellow: 관찰만
- Orange/Red: 사용하지 않음

### 4.2 Main Long Squeeze Filter

목적은 실제 롱 매매 후보를 찾는 핵심 필터다.

조건:

- OI Chg 4H ≥ 3%
- OI Chg 24H ≥ 8~10%
- OI / MktCap ≥ 0.2%
- Long 1H ≤ 49%
- L/S Ratio 1D ≤ 0.9
- FR AVG ≤ 0
- 가격이 상승 중이거나 주요 지지구간에서 버티는 중

시장모드별 사용:

- Green: 정상 사용
- Yellow: 75점 이상만 사용
- Orange: 일반 Main 진입 금지
- Red: 사용하지 않음

### 4.3 A++ Long Squeeze Filter

강한 알림 후보, 우선순위 후보, 러너 홀딩 후보를 찾는다. 단, 신규 추격매수 신호가 아니라 눌림 대기 신호다.

조건:

- OI Chg 4H ≥ 5%
- OI Chg 24H ≥ 15%
- OI / MktCap ≥ 0.3%
- Long 1H ≤ 46~48%
- L/S Ratio 1D ≤ 0.85
- FR AVG < 0
- Net Long 증가
- 가격이 너무 멀리 가지 않았거나 눌림 가능 구간에 있음

시장모드별 사용:

- Green: 적극 사용
- Yellow: 선별 사용
- Orange: 초저위험으로만 사용
- Red: 알림만, 진입 금지

### 4.4 Short / Long Ban Filter

숏 후보를 찾거나, 롱 우선 운용에서 위험한 롱 신규 진입을 차단한다.

조건:

- OI Chg 4H ≥ 3%
- Long 1H ≥ 55~60%
- L/S Ratio 1D ≥ 1.2
- FR AVG > 0
- 가격 상승 후 저항
- 매수 거래량 감소
- Net Short 증가 또는 Net Long 감소
- 상단 BSL / OB / FVG 저항 중첩

행동:

- Long Ban OFF: 롱 가능
- Long Ban ON: 신규 롱 금지, 기존 롱 익절 우선, 숏 모드 활성 시 숏 후보 전환

## 5. 점수 구간 해석

| 점수 | 구간 | 해석 |
| --- | --- | --- |
| 0~59 | Ignore | 무시 |
| 60~69 | Radar | 관찰만, 바로 진입하지 않음 |
| 70~74 | Early Main | Green Mode에서만 1차 소액 가능, Yellow에서는 대부분 패스 |
| 75~79 | Main Entry | 주 진입 구간, 좋은 눌림이면 1차 + 2차 가능 |
| 80~87 | Strong | 강한 후보/텔레그램 알림, 신규 추격 금지, 눌림 재진입/추가진입/보유관리 |
| 88+ | Overheat | 과열 가능성, 신규 진입 금지, TP/리스크 제거/재눌림 대기 우선 |

## 6. Pullback Engine v1

기본 시간축은 4H/일봉으로 시장 레짐과 큰 구조를 판단하고, 1H로 눌림구간을 계산하며, 15M으로 실제 진입 트리거를 확인한다.

핵심 기준:

1. 1H OTE: 최근 상승 impulse 기준 0.618~0.786 되돌림
2. VWAP 지지: VWAP line 또는 VWAP Band#1 부근
3. 돌파구간 리테스트: 이전 1H 저항 돌파 후 지지 전환 확인

보조 기준:

- FVG 중첩
- OB 중첩
- Sweep 후 회복
- MSB flip level 회복
- HTF 추세선 또는 수평 지지

Pullback Score:

- 핵심 기준 0~1개 충족: 진입 금지
- 핵심 기준 2개 충족: 일반 진입 가능
- 핵심 기준 3개 충족: A급 눌림
- 보조 기준 중첩 시 가산점

FVG는 v1에서 보조 가산점으로만 사용하며, FVG 단독으로는 진입하지 않는다.

## 7. 15M 진입 트리거

눌림구간 도달 후 15분봉에서 최소 1개 이상의 반응을 확인한다.

트리거:

1. 눌림구간 터치 후 15M 종가 회복
2. 긴 아랫꼬리 발생
3. 직전 15M 고점 돌파
4. 15M 거래량 증가
5. OI 유지 또는 재증가
6. 음펀비 유지
7. VWAP 재회복
8. MSB flip level 회복

기본 진입은 15M 트리거 1개 이상, A급 추가 진입은 2개 이상이 필요하다.

## 8. 최종 엔트리 조건

### 일반 롱

1. 점수 70점 이상
2. Main Filter 이상 통과
3. Long Ban OFF
4. Market Regime이 Green 또는 Yellow
5. Pullback Score 2점 이상
6. 15M 트리거 1개 이상
7. 스프레드/유동성 기준 통과

### A급 롱

1. 점수 75점 이상
2. Main Filter 강하게 통과
3. Long Ban OFF
4. Market Regime이 Green 또는 Yellow
5. Pullback Score 3점 이상
6. 15M 트리거 2개 이상
7. 유동성 충분

### A++ 롱

1. A++ Filter 통과
2. 점수 80~87
3. 추격이 아닌 눌림 진입
4. Pullback Score 3점 이상
5. 15M 트리거 2개 이상
6. Market Regime이 Green / Yellow / Orange 중 하나
7. Orange Mode에서는 초저위험으로만 진입
8. Red Mode에서는 진입 금지

### 숏

1. Short / Long Ban Filter 통과
2. 가격이 저항 구간에 위치
3. 매수 거래량 감소 또는 VPA 약화
4. 상단 BSL sweep, OB, FVG 저항 중 하나 이상 확인
5. 15M 또는 1H 기준 하락 전환 트리거 발생
6. 숏 모드가 활성화되어 있을 때만 진입

## 9. 분할 진입 및 리스크 관리

기본 진입은 3분할이다.

- 1차 30%: 70~75점, 눌림구간 도달, Pullback Score 2 이상, 탐색 진입
- 2차 40%: 15M 반등 확인, 구조 회복, 메인 진입
- 3차 30%: 미니 고점 돌파, 재가속 확인, A급 이상에서만 선택적 추가

1차 진입 후 구조가 깨지면 2차/3차 추가진입을 금지한다.

Daily Stop:

- 하루 누적 손실 -4% 도달 시 신규 진입 중단
- 하루 누적 손실 -6% 도달 시 전체 매매 중단

Weekly Stop:

- 주간 누적 손실 -8% 도달 시 리스크 절반 축소
- 주간 누적 손실 -12% 도달 시 해당 주 신규 진입 중단

## 10. SL / TP / Runner

손절은 점수가 아니라 구조 기준으로 한다.

롱 손절:

- 눌림구간 최저점 이탈
- 1H 핵심 지지 종가 이탈
- VWAP / OTE / Retest 지지 실패
- MSB flip level 재이탈
- 구조가 애매하면 지지선 아래 0.5~1 ATR

숏 손절:

- 저항구간 상단 돌파 및 안착
- BSL sweep 후 하락 실패
- 약세 OB / FVG 저항 무효화
- 15M/1H 구조 회복
- 구조가 애매하면 저항선 위 0.5~1 ATR

TP는 R 기준과 구조 기준을 함께 사용한다.

- TP1: +1R 또는 최근 1H 스윙 고점 중 더 가까운 값, 30% 익절, SL을 BE 또는 손실 최소 구간으로 이동
- TP2: +2R 또는 1H Weak High / VWAP Band#1~#2 / FVG midpoint, 40% 익절
- TP3: +3R 이상 또는 4H Weak High / VWAP Band#2~#3 / FVG full fill, 남은 30% 청산 또는 러너 유지

시장모드별 TP 운영:

- Green: TP2/TP3/러너 적극 운용
- Yellow: TP1 빠르게, TP2 중심, 러너 축소
- Orange: TP1 빠르게, TP2 욕심 축소, 러너 거의 없음
- Red: 신규 진입 없음

## 11. 시간 제한 및 쿨다운

Time Stop:

- 15M 기준 진입 후 8~10개 캔들 내 확장 실패 시 절반 축소 또는 전량 청산
- 1H 기준 진입 후 3~4개 캔들 내 힘이 없으면 감축

쿨다운:

- 동일 종목 신규 알림: 1시간 중복 알림 금지
- 동일 종목 진입 후: 2시간 신규 진입 금지
- 손절 후: 4시간 재진입 금지
- TP1 후 재진입: 새 눌림구간 형성 시만 가능
- A++ 알림: 1시간 내 중복 발송 금지

## 12. 유동성 / 스프레드 필터

- 대형 알트: 스프레드 0.15% 이하 선호
- 중소형 알트: 스프레드 0.3% 이하 선호
- 스프레드 0.5% 이상이면 자동진입 금지

추가 제외 조건:

- 24H 거래대금이 너무 낮음
- 호가 두께가 진입금액 대비 부족
- OI는 증가하는데 거래량이 없음
- 급등 후 거래량 감소
- 입출금/상장/김프 이슈로 가격 왜곡

1. 전 종목 스캔

6. 점수 구간 판정
